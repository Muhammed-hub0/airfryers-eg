# الإير فراير على أمازون مصر — تحديث تلقائي

مشروع صغير بيبني صفحة أسعار الإير فراير على `amazon.eg` ويحدّثها لوحده كل 6 ساعات عن طريق **GitHub Actions**، وينشرها على **GitHub Pages**.

- الأسعار والتوفر والصور بتتحدث من **Amazon Creators API** (الرسمي، مش سكرابينج).
- المنتج اللي يخلص أو يختفي بيتشال من الجدول تلقائيًا، ويرجع لوحده لو رجع متاح.
- منتجات جديدة بتتضاف تلقائيًا من البحث بنفس قواعدك (استثناء الإكسسوارات + البراندات المستثناة + حدود السعر).
- كل الروابط فيها `?tag=fineartslab-21`.
- نفس شكل الصفحة: عنوان + فلاتر (براند / سعة / وات / سعر) + جدول، من غير أي كلام فوق الجدول.

## الملفات

```
airfryers-site/
├─ scripts/
│  ├─ config.mjs       الإعدادات: البراندات المستثناة، حدود السعر، الموارد…
│  ├─ amazon.mjs       توكن Creators API + GetItems + SearchItems
│  ├─ naming.mjs       استخراج البراند/السعة/الوات وبناء الاسم العربي
│  ├─ update.mjs       التحديث: أسعار، حذف المنتهي، إضافة الجديد
│  └─ render.mjs       بناء index.html و all-airfryers.csv
├─ data/
│  ├─ offers.json      المنتجات (87 منتج مبدئيًا) + حالة كل منتج
│  └─ history.json     تاريخ الأسعار (سعر كل منتج مع الوقت)
├─ public/             اللي بيتنشر على Pages (بيتبني تلقائيًا)
└─ .github/workflows/update.yml
```

## خطوات التشغيل (مرة واحدة)

### 1) اعمل ريبو على GitHub

- اسم مقترح: `airfryers-eg` — **Public** (Pages مجاني للمستودعات العامة).
- ارفع **محتويات مجلد `airfryers-site`** نفسها (مش المجلد كحاوية)، يعني لازم يبقى في الجذر:
  `package.json` و `scripts/` و `data/` و `.github/`.

> أسهل طريقة من غير Git: GitHub → **Add file → Upload files** → اسحب كل الملفات والمجلدات → Commit.

### 2) فعّل GitHub Pages

Settings → **Pages** → **Build and deployment** → Source = **GitHub Actions**.

### 3) شغّل التحديث أول مرة

Actions → **تحديث أسعار الإير فراير** → **Run workflow** → Run.

بعد ما يخلص، الصفحة هتكون على:
`https://<اسم-حسابك>.github.io/<اسم-الريبو>/`
(والـ CSV على `.../all-airfryers.csv`)

من غير أي إعدادات تانية، الصفحة هتتنشر بآخر بيانات محفوظة في `data/offers.json` (الأسعار بتتجمّد لحد ما تضيف المفاتيح).

### 4) مفاتيح Creators API (عشان الأسعار تتحدث فعليًا)

1. سجّل في **Amazon Associates** (لو لسه) واطلب وصول **Creators API** من لوحة الحساب.
2. هتاخد **Client ID** و **Client Secret**.
3. في الريبو: Settings → **Secrets and variables → Actions** → **New repository secret**:
   - `CREATORS_CLIENT_ID`
   - `CREATORS_CLIENT_SECRET`
4. (اختياري) **Variables** → New variable: `PARTNER_TAG` = `fineartslab-21` (لو حابب تغيّره).

المفاتيح بتتخزن مشفّرة في GitHub ومش بتظهر في الكود ولا في الريبو.

## إزاي بيشتغل

| الخطوة | التفاصيل |
|---|---|
| **تحديث** | `getItems` لكل الـ ASINs (10 في الطلب) → سعر + توفر + صورة |
| **حذف** | لو المنتج خلص/مبقاش متاح دورتين ورا بعض (≈12 ساعة) → `active=false` ويتشال من الجدول. لو رجع متاح → يرجع تلقائي |
| **إضافة** | `searchItems` بكلمات: `air fryer`, `airfryer`, `قلاية هوائية`, `air fryer digital` × 3 صفحات، مع فلترة الإكسسوارات والبراندات المستثناة وحدود السعر (500–60000 ج.م) |
| **تكرار** | نفس المنتج بأكتر من ASIN → يظهر الأرخص بس |
| **النشر** | يبني `public/` → يرفعها Artifact → ينشرها على Pages، ويكومّت `data/` في الريبو |

الجدول الزمني: `cron: '0 */6 * * *'` (بتوقيت UTC) = **كل 6 ساعات**، وتقدر تشغّله يدويًا في أي وقت.

## تخصيص

| عايز تعدّل | المكان |
|---|---|
| براند مستثنى | `scripts/config.mjs` → `EXCLUDED_BRANDS` |
| حدود السعر | `scripts/config.mjs` → `MIN_PRICE` (أقل سعر يظهر) و `MAX_PRICE` (حد أمان) و `SEARCH_MAX_PRICE` (أقصى سعر للبحث عن جديد) |
| مدة السماح قبل الحذف | `scripts/config.mjs` → `MAX_STALE_DAYS` + `oosCount` في `update.mjs` |
| كلمات البحث | `scripts/update.mjs` → `SEARCH_QUERIES` |
| مواعيد التحديث | `.github/workflows/update.yml` → `cron` |
| شكل الصفحة | `scripts/render.mjs` |

## تجربة محليًا (اختياري)

محتاج Node 20+:

```bash
npm run update        # تحديث كامل (محتاج المفاتيح في متغيرات البيئة)
npm run render:only   # إعادة بناء الصفحة من آخر بيانات محفوظة
```

```powershell
$env:CREATORS_CLIENT_ID="..."; $env:CREATORS_CLIENT_SECRET="..."; npm run update
```

## ملاحظات مهمة

- **الأسعار لازم تيجي من الـ API**: برنامج أمازون الأفلييت بيمنع عرض أسعار مسحوبة (scraped)، وممكن يتقفل الحساب. عشان كده المشروع بيستخدم Creators API فقط.
- **الضمان والشحن** مش موجودين في الـ API، فهما قيم ثابتة (seed) وبيفضلوا زي ما هم. لو حابب تتشال خالص قول وأعدّل الأعمدة.
- **الأسماء عربية** وبتتبني من عنوان المنتج: `براند + سعة + وات + (تاتش/بكر) + (موديل)`.
- المنتجات اللي مش بترجع من الـ API 3 دورات → بتتشال (`not-found`)، لكن بتفضل محفوظة في `offers.json` وممكن ترجع.
- الصفحة فيها سطر إفصاح بأفلييت أمازون تحت الجدول (مطلوب من برنامج الأفلييت).
